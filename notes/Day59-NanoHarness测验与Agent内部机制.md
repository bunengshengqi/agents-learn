## 第 1 题：Agent 的核心循环是啥？

**题目**：Nano Harness 的 agentic loop 是下列哪一个？

- A. 调模型 → 立刻返回结果
- B. ✅ **调模型 → 解析 Python 代码 → 用工具执行 → 观察 → 重复直到 `final_answer()`**
- C. 模型返回 JSON → 解析 → 存数据库 → 结束
- D. 一直调模型直到它返回单词 "done"

**为什么 B 对**：这才是一个真正的「循环」——有**观察（observation）**、有**重复（repetition）**。A 是一次普通函数调用；C 是一次性 API 调用；D 只反复调模型却不执行代码，都不是 agent loop。

> 💡 对应 Day56：循环 = 调模型 → 跑代码 → 看结果 → 再调模型，转最多 50 次。

---

## 第 2 题：模型到底「输出」了什么？

**题目**：在 Nano Harness 里，模型生成的是什么？

- A. 英文散文，比如 "答案是 42"
- B. ✅ **Python 代码（调用工具），Agent 在沙箱里执行这段代码**
- C. JSON，由 Agent 解析
- D. 像 "list_dir" 这样的命令，由 Agent 翻译

**为什么 B 对**：Nano Harness 是 **code-first**——模型直接输出 Python 代码，Agent 解析并在受限环境执行它。A 违反「只输出 Python」的系统提示词；C 是别的框架（如 ToolCallingAgent）的做法，不是 nano_harness；D 模型是直接写函数调用，不是 Agent 去翻译。

> 💡 对应 Day55/56：模型不返回 JSON，而是返回可执行的 Python。

---

## 第 3 题：消息历史（记忆）是怎么用的？

**题目**：关于消息历史，正确的是？

- A. ✅ **历史随每次循环增长（模型输出 + 观察都追加进去），提供记忆**
- B. 每步清空历史以省 token
- C. 历史存进数据库供以后分析
- D. 历史不重要，只看最新一次模型输出

**为什么 A 对**：每轮都往 `messages` 里加 `assistant`（模型代码）和 `user`（观察结果），完整历史让模型能**引用之前的发现、避免重复失败**。B 错（不清空，否则失去记忆）；C 错（历史在内存里维护，不是数据库）；D 错（历史是决策的关键上下文）。

> 💡 对应 Day56：「完整消息历史 = 记忆」。模型每次都能回顾之前所有轮次。

## 第 4 题：`safe_path()` 是干嘛的？

**题目**：关于 `safe_path()`，正确的是？

- A. 允许读取系统上任意文件
- B. ✅ **防止目录穿越：检查路径是否仍落在 WORKSPACE 内**
- C. 可选，安全其实不需要
- D. 给路径加密以便传输

**为什么 B 对**：`safe_path()` 把路径解析成绝对路径，确认它还在工作目录内，从而挡住 `../../etc/passwd` 这类穿越。A 正好相反；C 大错（没它 Agent 能读 `/etc/passwd`）；D 错（它不做加密，只防逃逸）。

> 💡 对应 Day57：`safe_path()` 是路径限制的唯一入口，所有碰路径的工具都过它。

## 第 5 题：`exec_cmd()` 怎么保证安全？

**题目**：关于 `exec_cmd()`，正确的是？

- A. 允许任何 shell 命令运行
- B. ✅ **维护一份安全命令白名单，其它一律拦截**
- C. 有超时防止卡死（但白名单才是主要安全控制）
- D. 以管理员权限运行命令

**为什么 B 对**：`exec_cmd()` 只放行白名单里的命令（`ls`/`cat`/`pwd`/`echo`/`head`/`tail`/`wc`/`rg`），`rm`、`curl` 等全被拒。A 相反；C 描述的那句「有超时」本身也对，但**白名单才是主要安全闸门**（题目把它作为「也对但非主要」的干扰项）；D 错（普通用户权限，且受限）。

> 💡 对应 Day57：命令白名单是拦截「改状态/碰网络」命令的核心防线。

## 大佬总结：5 题覆盖了 5 个核心点

| 题 | 考的是什么 | 一句话答案 |
|----|-----------|-----------|
| 1 | Agent 循环 | 调模型→跑代码→观察→重复 |
| 2 | Code-First | 模型输出 Python，不是 JSON/散文 |
| 3 | 消息历史=记忆 | 每轮追加，完整历史提供上下文 |
| 4 | 路径限制 | `safe_path()` 防目录穿越 |
| 5 | 命令白名单 | `exec_cmd()` 只放白名单命令 |
